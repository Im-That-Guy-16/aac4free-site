# AAC4Free website

The public website for [AAC4Free](https://github.com/Im-That-Guy-16/AAC4Free), a free AAC app for iPad.

Live at **https://im-that-guy-16.github.io/aac4free-site/**

A static site (plain HTML and CSS, no build step) published with GitHub Pages from the `main` branch.

- `index.html`: the page
- `assets/styles.css`: styles
- `assets/img/`: screenshots from the iPad simulator, app icon and social preview image
- `assets/symbols/`: a few ARASAAC symbols used as decoration

Picture symbols are the property of the Government of Aragón, created by Sergio Palao for [ARASAAC](https://arasaac.org), and used under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
